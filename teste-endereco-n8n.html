Testador do endereço do n8n

Cole um endereço por linha (os candidatos a PUBLISH_URL). Para cada um, a página faz um envio de teste com uma chave falsa: nada é gravado no GitHub. Ela diz se o endereço serve para o mapa. Abra esta página pelo endereço do próprio site (https), para o teste valer como o do mapa.

Como ler: verde = pode usar no PUBLISH_URL. Amarelo = o servidor responde, mas algo impede o mapa de usar (a mensagem diz o quê). Vermelho = não alcançou, ou o navegador bloqueia.
